⌖ฝนใกล้ฉัน · Rain Near Me

กดอนุญาตเพื่อแสดงตำแหน่งของคุณ โดยไม่บันทึกพิกัดไว้ในระบบ

GPS ทำงานเมื่อคุณกดอนุญาตเท่านั้น พิกัดอยู่ในหน้านี้ระหว่างใช้งาน ไม่ส่งไปยัง TMD หรือ GitHub

พิกัดอุปกรณ์—
ความแม่นยำที่รายงาน—
เวลาได้ตำแหน่ง—

แผนที่ตำแหน่งแยกจากภาพเรดาร์ TMD ยังไม่ได้ซ้อนพิกัดบนภาพเรดาร์ เพราะไม่มีค่าพิกัดอ้างอิงของภาพที่ยืนยันได้

เปิดตำแหน่งบน OpenStreetMap ↗ (ส่งพิกัดให้ OSM เมื่อกด)

การกดแสดงแผนที่หรือเปิดลิงก์จะส่งพิกัดให้ OpenStreetMap เพื่อแสดงตำแหน่ง และไม่ใช่การคำนวณว่าฝนตก ณ จุดนี้

☂พยากรณ์ฝนใกล้ฉัน

กดอนุญาต GPS ด้านบนก่อน จากนั้นเลือกส่งพิกัดโดยประมาณเพื่อขอพยากรณ์

เมื่อกดดึงพยากรณ์ เว็บไซต์จะส่งพิกัด GPS ที่ปัดเศษเหลือ 2 ตำแหน่ง (ประมาณระดับกิโลเมตร) ไปยัง Open-Meteo ไม่ส่งพิกัดโดยอัตโนมัติ และไม่เก็บไว้ในฐานข้อมูลของเว็บไซต์ ผู้ให้บริการอาจได้รับข้อมูลการเชื่อมต่อของคุณ

โอกาสเกิดฝนสูงสุดใน 3 ชั่วโมงที่แสดง (แบบจำลอง)—
ผลรวมปริมาณฝนพยากรณ์ 3 ชั่วโมง (เมื่อครบข้อมูล)—

แหล่งข้อมูล: Open-Meteo • พยากรณ์อากาศไม่ใช่ภาพเรดาร์ TMD • ไม่ใช่ประกาศเตือนภัย

⌖ระยะห่างจากกลุ่มฝน

ยังไม่เปิดการคำนวณระยะห่างหรือเวลาเข้าถึงของฝน เพราะภาพ PNG ที่ได้รับยังไม่มีพิกัดภูมิศาสตร์ของแต่ละพิกเซลที่ตรวจสอบได้ โปรดใช้ภาพเรดาร์และประกาศทางการประกอบ

⚠ประกาศเตือนภัยทางการ

อ่านประกาศและเวลาเผยแพร่จากกรมอุตุนิยมวิทยาโดยตรง เว็บไซต์นี้ไม่ดัดแปลงประกาศเป็นการแจ้งเตือนอัตโนมัติ

เปิดประกาศเตือนภัย TMD ↗

การไม่เห็นประกาศบนหน้านี้ ไม่ได้หมายความว่าไม่มีความเสี่ยงในพื้นที่

◷พยากรณ์อากาศชลบุรี

ดูผลตรวจวัดจริงและพยากรณ์อากาศ 7 วันจากหน้าเว็บไซต์ทางการ (แยกจากภาพเรดาร์)

เปิดพยากรณ์จังหวัดชลบุรี ↗
▣ติดตั้งไว้บนมือถือ

Android: ใช้เมนูติดตั้งแอป / iPhone: Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม (ต้องมีอินเทอร์เน็ตเพื่อดูเรดาร์ล่าสุด)

☂ก่อนออกไปวิ่ง

ดูภาพย้อนหลังร่วมกับทิศทางการเคลื่อนตัวของกลุ่มฝน และเช็กประกาศเตือนภัยก่อนออกกำลังกายกลางแจ้ง
